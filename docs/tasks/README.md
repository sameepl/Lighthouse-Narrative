# Task cards

Issue-ready cards for the current milestone (see [`../ROADMAP.md`](../ROADMAP.md)). To start one:

1. Open a new issue from the **Agent task** template and paste the card's sections into it.
2. Add labels: `task`, the card's `zone:*` and `tier:*`.
3. Give an agent the prompt from [`../AGENT_WORKFLOW.md`](../AGENT_WORKFLOW.md) plus the issue.
4. When the PR merges, tick the box in the roadmap.

Cards say which tasks must merge first. Do not start a card before its dependencies are merged.
