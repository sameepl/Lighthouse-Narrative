# Game Brief (fill in; rough notes are fine)

## 1. Setting snapshot
Tone, tech level/era, and a one-paragraph "what is this universe like".

## 2. Protagonist
Who the player is, starting situation (role, ship, crew or alone).

## 3. Sample scene (most important)
One real situation, ~5 min of play: location, NPCs, the problem, and 2-3 ways to approach it.

## 4. Mechanics
- Core roll (e.g. 2d6 + skill + characteristic vs 8+): keep / simplify / hide?
- Stats and skills that matter most (names + typical ranges)
- Resources to track (stamina, credits, fuel, reputation, ...)
- Inventory/ship/crew elements

## 5. Visual identity
Colors, UI style (CRT terminal, clean minimal, ...), any existing art. "None" is fine.

## 6. Later / optional
Factions, key NPCs, central conflict, locations, naming/jargon, content lines, standalone vs. campaign adaptation.
